# Worst Fix Ever: Funniest Commit Message

One line of commit message for a bug fix that made everything worse.

`main.py` writes the entry to `/output/entry.txt`:

> fix: crash on startup - app no longer starts, so no more crashes

The fix for the startup crash was to stop the app from starting at all.
No startup, no crash — the bug report is technically closed.

It is the purest form of the worst fix: the repair did not mend the bug,
it removed the thing the bug lived in, and called the silence a success.

## Run

```sh
python3 main.py
```
